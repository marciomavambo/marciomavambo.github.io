Infraestrutura de Hardware

Servidor Host

Máquina dedicada atuando como node central do Home Lab.

  • Armazenamento SO: SSD de 120GB exclusivo
  • Firmware Base: Inicialização via Legacy BIOS
  • Sistema Base: Ubuntu Server (versão otimizada)

Pool de Armazenamento (Mídia)

Estrutura externa para abastecimento de dados e bibliotecas locais.

  • 3x Discos Rígidos Externos dedilhados para mídia
  • Diretórios mapeados diretamente para containers via Docker
  • Separação estrutural de Filmes, Séries e Animes

Ambiente de Containers

Camada de abstração para implantação ágil de microsserviços.

  • Orquestração nativa via Docker Engine
  • Interface de gerenciamento baseada em CasaOS
  • Isolamento de volumes persistentes de dados

Serviços e Entrega de Conteúdo

Jellyfin Media Server

Central de streaming privado de alto desempenho, rodando liso na rede doméstica.

  • Metadados e indexação automática ativos
  • Customizações aplicadas via CSS no painel
  • Streaming fluido sem engasgos locais

Tailscale Mesh Network

Rede privada virtual utilizada para interconexão segura de dispositivos externos.

  • Encaminhamento através de túnel criptografado
  • Compartilhamento seguro com TVs e smartphones externos
  • Dispensa a necessidade de abertura de portas no roteador

Automações e Comandos de Operação

Documentação de rotinas criadas para garantir a estabilidade do ecossistema:

Agendamento de Reinicialização Diária

Rotina configurada no cron do Ubuntu Server para reiniciar a máquina automaticamente todas as madrugadas às 01:00, com login automático configurado na inicialização.

# Edição das rotinas do sistema
sudo crontab -e

# Linha inserida para reinicialização diária às 01:00
0 1 * * * /sbin/shutdown -r now

Comandos de Verificação

# Monitoramento de processos ativos e carga da CPU
htop

# Validar montagem e espaço ocupado nos discos externos
df -h
